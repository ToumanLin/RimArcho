# RimArcho 亮点

[English](highlights.md) | 简体中文

RimArcho 1.0.5 发布文案：主标语与备选、三种篇幅的简介，以及支撑这些文案的产品亮点。这里提到的功能均已实现；所有数字都附有适用条件。详情见[用户指南](user-guide.zh-CN.md)。

## 标语

**RimArcho——知道你的游戏为什么崩的 RimWorld 启动器。**

备选：

- 一个懂 RimWorld 玩家的一站式启动器。
- 选 Mod、排顺序、检查、启动、查明报错原因，一个地方全搞定。

## 一句话简介

RimArcho 是一款免费的 RimWorld 启动器兼 Mod 管理器，专为装了几百个 Mod 的玩家打造：整理列表、检查能不能跑、启动游戏，再把报错追溯到引发问题的 Mod，证据也一并给你。

## 短简介（约 150 字）

重度 Mod 玩家的事，RimArcho 一个窗口包办：编辑列表全程可撤销，排序有解释，启动前查缺依赖、冲突、XML 补丁失败与 Harmony 补丁冲突。玩后读日志，合并重复报错，拿证据指出责任 Mod。还能锁定 Mod 版本，定格整合包，配上独立存档，检查旧档能否载入，通过 MCP 请 AI agent 帮忙。

## 长简介（约 400 字）

装上 300 个 Mod，RimWorld 就是另一款游戏；让它正常跑，本身就是一份活。RimArcho 就是为这份活做的。

**开玩前**，按游戏的读取方式检查列表：依赖、不兼容、加载顺序、游戏版本、重复副本，以及内容本身。合并各 Mod 的 Def，依次模拟 XML 补丁；失败时给出文件、行号和“目标 Mod 未启用”等原因。直接从 Mod 代码读取 Harmony 补丁。大多数问题一键修，每次编辑都能撤销。

**玩的时候与玩完后**，读取游戏运行中的 Player.log，把数百次重复报错折成一行，分清谁引发报错、谁只是出现在堆栈里。随附的 Archo Monitor 补上日志没写的信息：当时在加载哪个文件、处于哪个阶段。

**其他事也管**：锁定 Mod 版本，挡住工坊更新；把整份列表定格成带独立存档的整合包；查清旧档缺了某个 Mod 会丢什么；并行管理多个游戏版本；从工坊、SteamCMD、Git 或下载页订阅。从 RimSort、RimCrow 搬过来，导入一次就行。

## 产品亮点

### 结论有解释，判断有证据

- **每条结论都附证据和出处**：Mod 自身声明、推断、社区数据、游戏日志，或你设定的规则。
- **XML 补丁失败，告诉你为什么**：`target-inactive`、`target-missing`、`stale-name`、`node-absent`、`wrong-version-route`……按游戏应用补丁的方式模拟，附上文件和行号。
- **不用启动游戏，也能分析 Harmony**：哪些补丁修改同一目标，哪些前缀补丁可能跳过原方法，哪里有多个转译器，哪些同名 DLL 会相互遮蔽。
- **报错归因，分清角色**：源头、补丁方、依赖、被提及。Harmony 补丁方出现在堆栈里，不代表它就是罪魁祸首。
- **遵循游戏自己的规则**：版本文件夹、`LoadFolders.xml`、应用补丁后的 Def 继承。报告只涵盖游戏实际会加载的文件。

### 从玩家社区里学经验

- **内置来自 40,326 份玩家分享日志的数据**：Mod 漏写的依赖、容易出问题的组合，以及 3,947 种特定 Mod 的已知错误。
- **严重程度靠实测，不凭感觉**：用 6,734 份公开日志测量各类问题对实际报错的预测强度，让无害的规则违反不再吵你。
- **替代品也算数**：`alternativePackageIds` 和“Use This Instead 替代列表”都能满足依赖，让已停更 Mod 的汉化也能配合其续作使用。

### 放心折腾，留好退路

- **保存或启动之前，列表编辑不会写入游戏。** 改的是工作副本，支持 100 步撤销，还有完整版本历史。
- **备份后原子写入** `ModsConfig.xml`；在游戏 Mod 菜单或其他管理器里做的修改会被检测并保留，不会悄悄覆盖。
- **移除 Mod、存档、整合包时，送进回收站**；其他 Mod 通过链接接入游戏，无需复制。只有你要求时才修改 Mod 文件（取消隐藏、贴图转换），卸载前也会逐步预览。
- **暂存**：把一批可疑 Mod 暂时放到一边，一键全部放回原位。

### Mod 再多，也管得过来

- **每份副本都有记录**：工坊、本地、SteamCMD、额外文件夹、锁定版本。记录两次扫描之间的更新、移动和复制；Mod 暂时不见了仍保留在列表中，回来时自动重新关联。
- **锁定版本，挡住工坊更新**；新版来了先比较，准备好了再更新。
- **整合包**：把列表定格为一套确定的 Mod 文件，配上独立存档；导出为 `.archopack`，也可选择精简贴图。
- **标签视图与标签管理器**：跨数千个 Mod 分组、重命名、合并标签，并为标签添加注释。
- **更新按影响标注**：会影响启动、留意、只是内容。也能批量全部更新。
- **贴图优化**：将 PNG 转为 DDS，加快加载；保留原图，一键撤销。
- **搜进每个 Mod 内部**：Def、补丁、反编译的 C#，找到结果就陆续显示。
- **支持模糊搜索的命令面板**（`ctrl+k`）：`lib hug` 能找到 HugsLib，`vanilka expnded` 能找到 Vanilla Expanded。

### 不只管 Mod 列表

- **每个存档都能查“能不能载入？”**：“缺少它时载入，会丢失 3 名 Kurin_Race 种族的殖民者、1 个派系、3 件物品”，并提供一步修复。
- **从存档回看殖民地历史**：财富、殖民者、事件，沿时间线展开。
- **多个游戏版本并行管理**，需要时可各用各的存档；还能用 SteamCMD 下载另一个版本。
- **边玩边看实时日志**；启动前检查内存，发现 RAM 可能不足时提醒你。
- **多种来源都能订阅**：Steam 客户端、SteamCMD（无需 Steam 客户端）、Git 分支、标签或提交，以及包括 LoversLab 在内的下载页。SteamCMD 批量下载后，还能转为真正的 Steam 订阅，为作者贡献订阅数。
- **没有 Steam 账号也能用**：照样管理本地游戏和 Mod。

### 一个程序，四种用法

- **桌面窗口**、**终端界面**、**可用于脚本的 CLI**、**MCP 服务**，共用同一套代码和事实；窗口与终端的大多数按键也相同。
- **对屏幕阅读器友好**：页面、控件、行和状态都有名称，进度与错误也会播报。
- **AI agent 也是正式用户**：一行配置接入 Claude Code、Codex 或任意 MCP 客户端。agent 看到相同的证据，修改进入你的撤销历史，只读工具也有明确标记。
- **试运行**（CLI 与 agent）：用临时数据启动真实游戏，进入主菜单或测试地图，再与上次游戏的报错比较。
- **英语、简体中文随时切换**，无需重启。

### 少占资源，多留给游戏

除另有说明外，以下数据测于 Windows 11、SSD、1,354 个 Mod 文件夹、启用 485 个 Mod 的列表：

- 终端界面在 0.10 s 内显示首屏（扫描后首次启动为 0.35 s），空闲时占用约 47 MB。
- 在含 6,574 份副本、启用 601 个 Mod 的合成数据环境中，窗口启动时约占 180 MB，访问所有页面后约占 289 MB（整个进程树，单次运行）；停留在“启动”“Mod 库”“能不能跑”“设置”页面时，空闲 CPU 占用为单核的 0.2–1.1 %。
- “搜索文件”在 1,354 个 Mod 中找到首个匹配项用时 34 ms（合成数据 Mod 库）。
- 没有后台服务：关闭 RimArcho 后，不再占用资源。

## 从其他管理器迁移

RimArcho 能找到 RimSort 列表和用户规则，以及 RimCrow 数据库和已保存列表，先预览，再导入列表、别名、备注、分组（转为标签）和规则。原管理器的文件保持原样。也能读取 RimSort、RimCrow、RimWorld 列表格式、分享码、`.rml`、存档、Rentry 页面和 Steam 合集。

## 运行要求

- Windows 10 或 11（64 位）。窗口使用 Windows 已自带的 Microsoft Edge WebView2。
- 面向 RimWorld 1.6 和 1.7 打造；也能管理更早版本的安装。
- 可选：ilspycmd（需要 .NET SDK），用于读取 Mod 的 C# 代码。
- 免费开源，采用 MIT 许可证。程序没有代码签名，Windows SmartScreen 可能会提示一次。
