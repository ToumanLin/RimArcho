### 2.16.1 Scheduled behavior table

This table governs periodic scheduling, polling, idle release, expiry, and waits / retries involving network, disk, processes, memory. Automatic-check authorization / notifications: §2.16; performance targets / measurements: §10, 07 §6.

- **Triggers / intervals**: periodic work exists only while its window / task lives; post-cycle intervals exclude work duration; on-demand expiry has no separate timer.
- **Interfaces / networking**: interface column lists actual entries; on-demand CLI / MCP never starts automatic maintenance. Local APIs, file / process checks are not network activity.
- **Settings**: No means no player-configurable interval. Five maintenance categories share `updates.auto` default `on`, `updates.interval` default `normal`.
- **Locations**: relative to `internal/`; `JS/` means `internal/surface/gui/assets/js/`. IDs are spec references.
