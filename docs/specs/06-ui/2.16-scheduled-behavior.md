# 06 · Interface · Scheduled behavior table (§2.16.1)

> Part of [06 · Interface](README.md). Section numbers run through all of 06. References use `06 §2.16.1`.

### 2.16.1 Scheduled behavior table

This table governs periodic scheduling, polling, idle release, expiry conditions, and waits and retries involving the network, disk, processes, or memory. See §2.16 for automatic-check authorization and notifications, and §10 and 07 §6 for performance targets and measurements.

- **Triggers and intervals:** periodic work exists only while its window or task is alive. An interval restarted after a cycle excludes the work's duration. An on-demand expiry check has no separate timer.
- **Interfaces and networking:** the interface column lists the actual entry points. On-demand CLI and MCP operations never start automatic maintenance. Local APIs, file reads, and process checks are not network activity.
- **Settings:** No means there is no player-configurable interval. The five maintenance categories share `updates.auto`, default `on`, and `updates.interval`, default `normal`.
- **Code locations:** paths are relative to `internal/`; `JS/` means `internal/surface/gui/assets/js/`. The IDs are used in specification references.
