**Actions**: six copy-detail actions, applicable only, fixed order:
1. **Restore** (`unhide`): make another manager's hidden copy visible to game.
2. **Unsubscribe** (Workshop) / **Delete** (own copy): real unsubscribe through running Steam (08 §10); Steam then deletes folder, so show `--dry-run` text naming folder then confirm like deletion. Refuse running game. Enabled/used copies are allowed without first removing list entries; warn naming lists, then execute after confirmation and leave missing entries, per item in batch. Only Steam unavailable/missing `steam_api64.dll`/DLL load failure falls back to Workshop page with reason and manual-unsubscribe instruction. Delete recycles (`trash`, 08 §7), only RimArcho's own `Mods/`/lock-library copies, SteamCMD copies (no subscription redownload), residue/hidden Workshop folders. Usage warns similarly. Refuse a link itself (`_Link_*`, etc.), never modify target. Preview then confirm.
3. **Resubscribe**, Workshop originals including residue: numeric Workshop ID, copy not link/locked. Preview/confirm. Subscribed copies first unsubscribe; after Steam confirms, RimArcho recycles original folder, verifies path absent, then subscribes. Cleanup failures are not subscribed and report reason. Preview explicitly warns recycling/redownload loses local edits. Allow enabled/used copies, refuse running game; retain original path/Workshop ID/Instance/Lineage and list references. Residue skips unsubscribe/cleanup. After confirmed subscription, including residue, request Steam download and wait for files with per-item background progress; stalled downloads suggest checking Steam. Steam unavailable uses same webpage fallback. Calls: 08 §10.
4. **Back up locked version** (= move into lock library, below): extra `Mods/` copy.
5. **open the folder**.
6. **Open webpage**, with Workshop ID.
