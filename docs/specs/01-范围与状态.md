## 3. 不做

- 通用的工坊浏览器和工坊搜索。“值得玩”只从玩家已有的 Mod 和其他玩家验证过的整合包出发（00 §2）。
- 订阅 Git 来源；用 SteamCMD 下载 Mod（SteamCMD 目录只读取和部署，08 §3）。
- 自动更新 RimArcho；常驻后台进程；开放任何网络端口（MCP 只走 stdio）。
- 主题系统、休眠屏、推荐清单导出（RimCrow 有，RimArcho 不做）。
- 获取 Mod 的枢纽：工坊检索、Git 仓库订阅（RimCrow“库存枢纽”的另外三页）。管理已在本机的 Mod 是 Mod 库存页（06 §2.9），要做。（2026-10-21 更正：最初的“不做库存枢纽”是 MVP 的范围，重写规格时误写成了永久不做。）
- 只在编译整合包时优化贴图，不改玩家的原 Mod（08 §5.2）。
- 购买代码签名证书。README 说明首次运行时 SmartScreen 的提示。
- 替外部 agent 审批权限：外部 agent 的写操作是否放行由它的 harness 决定，工具按 MCP 规范标注 `readOnlyHint` / `destructiveHint`（05 §5.2）。内置 Archo 的写操作走 RimArcho 自己的确认（09 §2）。

## 4. 写文件清单（安全底线）

RimArcho 只写下面这些地方，其他一律不碰。每个会写磁盘的动作都要能预览（CLI 的 `--dry-run`、界面里的预览）、要玩家确认（界面）或明确执行（CLI 不带 `--dry-run`），并且能撤回，或者说明为什么不能撤回。

| 写什么 | 什么时候 | 规则 | 规格 |
| --- | --- | --- | --- |
| RimArcho 自己的数据目录（`%APPDATA%\RimArcho\`） | 随时 | 数据目录不能与游戏目录、用户数据目录、任何来源根目录互相包含，`env add/set` 和 `scan` 时检查 | 07 §3 |
| `<用户数据目录>/Config/ModsConfig.xml` | 启动方案、写入游戏 | 先备份为 `ModsConfig.xml.rimarcho.bak`（只留一份），再写临时文件原子替换 | 04 §4.1 |
| `Mods/` 下以 `_Archo_` 开头的目录链接 | 启动方案、写入游戏 | 只建、删带这个前缀的链接；从不写链接目标；同名但不是链接的目录不动并报错 | 08 §3 |
| `Mods/` 下以 `!ArchoPack_` 开头的目录链接 | 启动整合包；切回方案时清理 | 同上 | 08 §5.3 |
| 把 `Mods/` 里多出来的同 Lineage 副本收进锁定库 | 玩家在 Mod 库存确认后，或 `library move-to-locked` | 同卷改名；跨卷复制、核对后原目录进回收站；只移整个 Mod 文件夹，且同 Lineage 还有别的副本；有指向文件夹外的链接时拒绝；没有 `.rimarcho/origin.json` 时写一份；Instance 不变（已实现） | 06 §2.9 |
| 锁定库（设置项 `lock.dir`，默认 `%LOCALAPPDATA%\RimArcho\locked`）下的新文件夹 | 玩家锁定一个 Mod、更新锁定版本时 | 只新建，名字被占用时加后缀，从不覆盖；写 `.rimarcho/origin.json`；锁定库与数据目录、各来源根目录互不包含 | 04 §7 |
| Monitor 目录（设置项 `monitor.dir`，默认 `%LOCALAPPDATA%\RimArcho\monitor`）下的 `ArchoMonitor-<版本>/` | 安装、更新随附的 Archo Monitor 时 | 只新建版本目录（先组装临时目录再改名）；同版本内容不同时只替换预发布版本的目录，且没有游戏在运行；与数据目录、各来源根目录互不包含 | 08 §9 |
| 把 `Mods/` 里 RimArcho 建的旧副本移进锁定库 | 第一次更新它、或 `pin --move-to-library` 时，玩家确认后 | 只移带 `.rimarcho/origin.json` 的目录；同卷改名，跨卷复制并核对后把原目录移到回收站 | 04 §7.4 |
| 把 `About.xml.disabled` 改回 `About.xml` | 玩家确认 unhide / unpin 时 | `About.xml` 已存在时拒绝 | 08 §6 |
| 移到回收站 | 玩家确认后 | 只接受：工坊或 SteamCMD 来源里的 Instance 真实目录、整合包目录、存档文件；回收站不可用时拒绝，从不永久删除 | 08 §7 |
| 存档备份 | 玩家确认后 | 复制到 `<数据目录>/backups/saves/<时间>/`，不改原存档 | 10 §4 |
| 整合包的数据目录 `<包>/userdata/` | 启动整合包 | 首次启动时从环境复制设置（不含 ModsConfig.xml） | 08 §5.3 |

从不做的事：
- 不修改工坊条目里的文件。工坊目录里只会发生两件事：玩家确认后把 `About.xml.disabled` 改回 `About.xml`，或把整个条目文件夹移到回收站。
- 不往工坊目录写标记文件（Steam 校验或更新时会删掉它）。
- 不跟随指向 Mod 目录以外的链接写入；防止路径穿越。
- 只有玩家触发的动作才联网：社区数据更新（04 §6）、工坊简介和图片（可在设置里关闭，06 §4.3）、读取 Steam 合集（04 §9）、Steam 订阅与退订（1.2）、调用模型（征得同意后，09 §3）。
