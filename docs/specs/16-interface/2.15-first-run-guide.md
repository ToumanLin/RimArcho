### 2.15 First-run guide

The first-run guide is implemented in the GUI (`guide.js`). It has three steps, each allowing a return to the previous step:
1. **Find environment**: switch between the following two methods:
   - **Existing game**: automatic discovery (03 §3.2) lists the games it finds and allows multiple selection. Alternatively, Add this directory selects a folder directly (§3.1 rule 12; the TUI still accepts typed paths). Prefill the name with the game version (`1.6`, or `1.6-2` if the name already exists).
   - **Download a version** (11 §3): if SteamCMD is missing, explain that it will be downloaded from Valve and show the size and location. Download it only after the player clicks Download SteamCMD. Then list the SteamCMD branches (the current stable version, beta, and older versions, with Steam's descriptions and dates), the game directory (default `<drive>\Games\RimWorld <version>`; clicking the address or Change opens the folder picker), and an optional Steam account-name override. The default is anonymous; a blank field uses settings, while explicit anonymous overrides the saved account. Explain that the password and Steam token are entered only in SteamCMD's own window. During download, show the stages (start, login, download, and verification), a progress bar, and mapped, safe stage descriptions. Never forward raw authentication logs. Explain failures in plain language and allow retry. Success registers the environment in the same way as an existing game and enters step 2.
2. **Read Mods**: scan in a subprocess and show progress (§8.4). If the shared Mod folders have already been scanned, read only the new game's `Data` and `Mods` (`scan --game-only`, 04 §1.1). The row says that these directories contain N Mods.
3. **Where to start**: choose the game's current list (import ModsConfig.xml as the first plan), migrate from RimSort or RimCrow (import lists and player data, 07 §6, §7), or open a pack or Steam collection (`pack import`, `archo collection`). Select a pack with the system file dialog and paste a collection URL separately; never require typed local paths.

Import uses `view.ReadImport` → `view.PreviewImport` (show the preview first) → `view.ApplyImport`. Add environment on the environment page starts at step 1.
