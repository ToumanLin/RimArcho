### 2.18 Import

Import is one page where every import starts, so a player who wants to bring something in finds it without knowing which feature owns it. It is the last entry in the sidebar's Library group (§2.1), after Game Configs, with no `shift+` key: `shift+1–8` stay the eight pages the TUI also has (§3.5). The breadcrumb is “library / import”. The TUI has no Import page; its imports are commands (07 §6.2, §7; 10 §4).

**Entries**: the sidebar entry; `i` in the list editor (All lists' `i` keeps its own import mode); a file dropped anywhere outside an import area; Settings' “import from RimSort, RimCrow or RimPy” row (§2.14); the command palette's “import a list”; and the first-run guide's “move over from RimSort, RimCrow or RimPy” and pasted collection link (§2.15, which return to the guide when done). They all open this page. All lists' “new / import” form keeps its own import mode for now (§2.17), and the guide still chooses a pack itself.

**Found on this computer** comes first. `app.FindManagerImports` reads the bounded locations of 07 §6.2 (RimSort, RimCrow and RimPy) without writing anything; it never searches whole drives. Each row shows the manager as a button, the kind (list, player data or user rules) and the full path (§3.1 rule 12). A list opens the list preview below; RimCrow player data, RimSort player data (an instance's `aux_metadata.db`) and RimSort user rules open the migration preview (07 §6.2–6.4), with RimCrow's profile checklist. The preview counts notes, tags and tag colours. While discovery runs the section says “looking for RimSort, RimCrow and RimPy…”; with nothing found, “No RimSort, RimCrow or RimPy data found.”

**From a file or pasted text**: a muted line names what can be imported (RimArcho, RimSort, RimCrow, RimPy and RimWorld lists, saves, packs, share codes, packageIds and Workshop links) and says nothing changes before the player confirms. One text area accepts a share code, a Steam collection or Rentry link, or a copied list, with “paste from the clipboard” and “preview”. “choose a file…” opens one native dialog (`API.PickAnyImport`) for lists, saves, packs (`.archopack`) and other managers' data (`.db`, RimSort's `userRules.json`), and sends the file where it belongs: a pack is imported at once into the packs (`API.PackImport`, 10 §4), with the result and “open packs”; RimCrow databases and RimSort rules (`API.ManagerFileKind`) get the migration preview; everything else gets the list preview. A dropped file has no path, so a dropped pack or database asks the player to choose it with “choose a file…”; a dropped list or save is read and previewed.

**List preview and destinations** are those of the editor's import subpage (§2.17): the source, game version, installed and missing Mods, then a new list, replacing the selected list, or adding only the missing Mods, and “follow this collection from now on” for a Steam collection. The selected list is the current list, or the list selected on All lists or in the editor when the page was opened from there. “cancel” (`esc`) returns to the page the player came from.
