### 2.18 Import

The Import page (`importhub.js`, sidebar Library › Import after Lists, no `shift+` key, §2.1) holds every kind of import in one place, so none is hidden in Settings or reachable only on a first run. The lead says every import is previewed first and none writes the game's files. It holds no import logic: each box opens a flow that already exists. The boxes come from `importways.js`, which the first-run guide's last step shares (§2.15); each has a title, one line on what it brings and its buttons on a shared bottom line.

- **A game**: the games already added, "add a game", which opens the guide's first steps (§2.15, as the Game page's "add a game"), and, when a game is added, "copy a game…", which opens them on the copy way (03 §3.5).
- **Move over from RimSort or RimCrow**: discovery (07 §6.2) runs while the page shows, read-only, and the box says what it found per manager ("found RimSort: 3"), or "No RimSort or RimCrow data found."; "import…" opens the manager import flow (lists and player data, §2.15).
- **A mod list**: a field for a share code, a collection or Rentry link or packageIds ("open" or `enter`), and "choose a file…" (the native dialog). Both open the list importer with its preview and destinations (§2.17, 07 §7).
- **A pack**: "choose a pack…" imports an `.archopack` (10 §4), says the result and opens Packs.

A file dropped anywhere in the window still goes to the list importer (§2.17). Cancelling the list importer from here returns to the Import page.
