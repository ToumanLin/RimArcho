### 2.13 Archo panel

**Not implemented (1.1).** The Archo panel is a right-side panel that opens from any page; see 15 for its form, tools and permissions. Every reference to the AI assistant in the interface uses the name Archo and its portrait (`internal/icon/portrait.svg`), for example "Ask Archo to analyze this error." Where the portrait would be too small to recognize (buttons, card headings and list rows), the bow symbol stands in for it (§7). The TUI has no Archo panel (15 §6).

**Texture optimisation** (Library › Texture optimisation; GUI `textures.js`, `view.TexturePage`; the TUI uses the command panel and the `shift+7` text panel): like other pages, it has a page heading with actions at the right (download todds…, convert, stop, and remove every converted texture…). Below the heading, it shows the PNG textures in the current plan (or all Mods), their estimated sizes, and progress (10 §2). The player decides when to count. Opening the page reads only the encoder information and the number of Mods in scope (`API.TexturesInfo`); it reads no textures. The bottom line says "not counted yet: “count the textures” reads every PNG to show what is there and what converting saves", with "count the textures" and "convert" at the right. Only clicking "count the textures" starts reading in the background (`API.Textures`, §3.1 rule 9). The list shows first and the sizes fill in row by row. While counting, both dropdowns are disabled and the button becomes "stop counting"; stopping restores the previous result. Changing the scope or scale does not count again: the previous figures stay, with "the choices changed since this count; “count the textures” counts again". After a conversion or removing every converted texture, the page says "the textures changed since this count; “count the textures” counts again". Conversion works without counting, because it converts only new or changed PNGs; the confirmation says so ("not counted yet: only new or changed PNGs are converted, those already done are skipped"). If counting has run and there is nothing to convert, "convert" is disabled. Each Mod's summary is cached by the fingerprint of its texture paths, sizes and modification times, together with the options. On reopening, the page checks the metadata first and fills in unchanged figures directly. Changes to files that have not been scanned also invalidate the cache. Result polling is batched at the interval in §2.16.1 G06; unchanged rows keep their nodes and shimmer. Settings keeps only the location of the todds encoder.
