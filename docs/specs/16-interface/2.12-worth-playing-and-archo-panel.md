### 2.13 Archo panel

**Pending (1.1)**. The Archo panel is a right-side panel that can be opened from any page; see 09 for its form, tools, and permissions. Every UI reference to the AI assistant uses the name Archo and its portrait (`internal/icon/portrait.svg`), for example, “Ask Archo to analyze this error.” Where the portrait would be too small to recognize (buttons, card headings, and list rows), use the bow symbol instead (§7). The TUI does not yet support the Archo panel (15 §6).

**Texture optimization** (GUI `textures.js`, `view.TexturePage`; the TUI uses the command palette and the `shift+7` text panel): this page is under Library. Like other pages, it has a page heading with actions at the right (download todds, convert, stop, and restore all). Below the heading, it shows the PNG textures in the current plan (or all Mods), their estimated sizes, and progress (10 §2). The player decides when to collect statistics (2026-10-24). Opening the page reads only the encoder information and the Mod count within the scope (`API.TexturesInfo`); it does not read textures. The bottom line says “Not scanned yet,” with “count the textures” and “convert” at the right. Only clicking “count the textures” starts reading in the background (`API.Textures`, §3.1 rule 9). Show the list first and fill in the sizes row by row. While counting, disable both dropdowns and replace the button with “stop counting”; stopping restores the previous result. Changing the scope or scale does not recalculate the statistics: retain the previous figures and say “Options changed… click count the textures to recalculate”. After conversion or restoring all textures, say “Textures have changed since…”. Conversion is available without statistics because it converts only new or changed PNGs; state this in the confirmation. If statistics have been collected and there is nothing to convert, disable “convert.” Cache each Mod's summary using the fingerprint of its texture paths, sizes, and modification times, together with the options. On reopening the page, check the metadata first and fill in unchanged figures directly. Changes to files that have not been scanned also invalidate the cache. Batch result polling at the interval in §2.16.1 G06; retain the original nodes and shimmer for unchanged rows. Settings retains only the location of the todds encoder.
