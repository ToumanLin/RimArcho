## 术语

| 现在 | 问题 | 建议 |
| --- | --- | --- |
| 游戏配置 | 核心概念，第一次出现没有解释；和游戏的 Config 文件夹、“复制 main 的设置”混在一起 | 侧栏和启动页叫“游戏”，只在游戏配置页本身保留这个词并加一行解释：“一个游戏目录，带自己的存档、设置和当前列表” |
| 托管目录 | 新玩家看到的第一个词 | 跳过这一步；保留的话说“RimArcho 下载的东西放在哪里” |
| 锁定这个版本、锁定库 | 听起来像“冻结列表”或“禁用” | 保留这个版本；锁定库在设置里没用过就不显示 |
| 扫描、重新扫描、重新检查文件、读一遍 Mod、重新扫描 Mod 文件夹 | 五种说法对应两个动作 | 只用“重新扫描”（读文件夹）和“重新检查”（查列表问题） |
| 功能型、非功能型 | 英文界面没用这个词，中文用了 | 改成“界面、性能、修复类 Mod”或“存档里看不出的 Mod” |
| 跟着 Steam 合集 / 关联 | 同一张卡片上标题和按钮用了两个词；术语表写的是“跟着合集” | 按钮也用“跟着” |
| 来源不明、打过补丁的方法出错 | 崩溃时玩家最先看到的，看完不知道该做什么 | 第一行说“游戏代码里有 502 个报错，没找到是哪个 Mod”，下面给“先试试” |
| Archo Monitor | 第一次出现时后面跟着命令行 | 第一次写“游戏内助手（Archo Monitor）”，配安装按钮 |
