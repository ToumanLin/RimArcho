Where players review tags: two drafts (GitHub #28)

What exists: tag colours, the first tag's colour band in every editor row, the Tag manager (note, rename, merge, colour, all tags with counts) and -has:tag. What the player could not find: the Tag manager is reached only from Disabled's tags view or the Mod library's Tags view, and nothing says how many enabled Mods have no tag.

A · A tag coverage bar in Enabled's heading (chosen)

Enabled's heading draws its Mods by their first tag's colour: one segment per colour, grey for a tag with no colour, hatched for no tag, with the untagged count printed. Clicking a segment shows that tag in the Tag manager (the details, as a tag clicked in a Mod's details does today), whose all tags chips are the overview. Clicking the hatched part filters to has:notag. The filter bar's Tags group ends with a no tag value. No row changes: rows stay 28px.

B · A Tags page in the sidebar

A new page lists every tag as a table: colour swatch, name, Mods, enabled, a bar of its share, the note; a last row No tag. Editing opens the Tag manager. It is a full page of text and numbers the Mod library's Tags view already has, and the player leaves the list they are checking.
