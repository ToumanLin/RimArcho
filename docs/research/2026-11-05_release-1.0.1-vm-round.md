# Release 1.0.1: pre-release VM round

Date: 2026-11-05. The round walked [release-vm-tests.md](../release-vm-tests.md) before 1.0.1. The rows were merged into 13 VM sessions plus one host check. 1.7 parts were left out by decision, and MCP-with-agent parts were left out because the two MCP eval rounds already cover them ([round 1](2026-11-04_mcp-transcript-review.md), [round 2](2026-11-05_mcp-transcript-review-round2.md); 48 runs).

Evidence is kept outside the repository: `D:\RimArcho-test\release-1.0.1\<VM>\<session>\`, round copies in `D:\RimArcho-test\rounds\`, and the shared brief in `BRIEF.md`. Each session was run by an agent following that brief. The rules were: real data in the VM only; destructive steps only on Mods tagged "I Dont Need It"; new save names only (saves reach Steam Cloud); stop after two confirmed app bugs.

## Result

19 app bugs were found and fixed. Each fix has a regression test, and the fixes were retested in the VM. All retests passed.

## Not covered

These parts stay in the table:

- 1.7 parts of every row.
- The TUI and Windows Terminal: input from computer use does not reach the guest.
- Real-mouse checks: native drag at 150% scaling, window buttons, return by click or Alt+Tab. The drag checks used synthetic browser events; Ctrl+click with those did not extend the selection, which was counted as inconclusive.
- LoversLab session and the real SteamCMD download: they need the user's credentials.
- In-game settings windows (Archo Monitor, HugsLib): the round driver cannot click in the game.
- Uninstall: the shutdown or sign-out reason, the English interface, and a relocated source library.
- `Tried to …` errors and lord attribution: they need a classroom or party in the game. The real corpus already covers them (1,073 lines).
- The relay's real send (relay not deployed).

## Open items (not fixed)

- `test run` compares with the newest Player.log even when it comes from an unrelated, older list. The snapshot's 10-24 log gave `643 fixed`. This needs a decision: compare only with a log of this list, or say how old it is.
- Settings shows CLI output in English after some actions (`src:extra added`, `set data.rules.url = …`).
- `plan new X --from default` prints a raw error (`open default: The system cannot find the file specified`).
- The command panel keeps its last text after Enter or Esc.
- `player_log.present` counts 0 while informational clusters say `before: present` (spec: the count covers all clusters).
- `saves list` takes about 2 ms per save after indexing (target about 1 ms; 714 ms for 205 saves).
- After `gc`, an "added" row can show an empty package ID (`info added pkg:`).
- `Workshop 1578693166` in the subscribe preview is still English.
- A bare misspelled `PatchOperationAddd` has no "did you mean"; the namespaced one has.
- After a dialog is confirmed with Enter, focus goes to the page body instead of the button that opened it.
- The window buttons have low contrast over the launch page background.
- The editor did not show an `archo move` made from the CLI while it was open, even after a reload.
- A framework that is installed but not in the list is described as "which no installed mod defines".
- `patches --mod X` suggests `archo patches --failed` and drops `--mod`; a missing Workshop dependency prints two `fix:` lines for one link.
- English text has no plural forms ("1 error groups"), by design.

## Table and tooling changes

- Row "A `Player.log` … counted as the last run (P25)": its first step saved the list, so the log is then attributed to that write, and "source unknown" cannot appear. The row now starts from a home where RimArcho has neither launched the game nor saved the list.
- `dist\archo-1.0.0-windows-amd64.zip` on the host is a dirty rebuild that already uses schema 31. It is not the 1.0.0 release; build old versions from their tag.
- `vm.ps1`, `round.ps1` and `smoke.ps1` take `-VMX`, and each VM gets its own transfer folder (`115249a1`).
- Clones resumed from RimArcho-Real-Vulkan keep Player-Test's MAC address. They get no DHCP until the guest's MAC is changed, and their Steam sign-in kicks Player-Test's Steam (Session Replaced). Clones started from the powered-off RimArcho-Eval-Staged4 get their own MAC. Steam rounds run only on Player-Test.
- Test runs work only from an interactive guest session.
