## Found and fixed

Each fix is its own commit with a synthetic test, its spec section and a CHANGELOG entry, and was checked again in the VM on the first build that has it.

- **SteamCMD failed under a Windows user name with non-English letters** (row S11, 17 §2.1, 11 §1). SteamCMD under `C:\Users\新玩家\AppData\…` could not start. It now starts through an ASCII junction `C:\Users\Public\RimArcho\steamcmd-<hash>`; the branch list (`env branches`) goes through it too. 1ed1d69a, 164513dd; RC c2/c3: two anonymous subscriptions and `env branches` passed.
- **What RimArcho did: an unsubscribe refusal was not logged, the reason was repeated, "1 save" was not translated** (row "What RimArcho did", 16 §2.18). A refused Workshop unsubscribe is now one entry with Workshop links, the reason once, save counts in the player's language. ab3845a5; RC c2.
- **Can it run: Space on a maintained replacement** (row "Ignore a maintained replacement", 16 §4). Space now offers one "use B instead", as the window does. 7d56e804; RC c3.
- **TUI navigation row showed the wrong shift digit** (row 149, 16 §9.1). Each entry shows its own shift+N. 455dd698; RC c3.
- **TUI idle GC spin on a big list** (row 149, 17 §7.3, 18). The 1,292-Mod list's live heap (about 48 MiB) sat above the 40 MiB soft cap, so the collector ran without end at idle. The cap is now 256 MiB, a ceiling rather than a target. `TestTuneProcessLiveHeapAboveFortyMiB`; a4166f7c; RC c4: idle CPU back to 0.
- **A second home could not choose its own `local.dir`** (row "Uninstall leaves another home's links", 02 §2, 17). On a fresh `RIMARCHO_HOME`, `config set local.dir` was refused because the VM home's default folder was in use. A home with no Game Config, no source and no `local.dir` of its own may now choose one. `TestManagedRootOfAHomeBesideAnother`; 34ceaa85; RC c5.
- **Uninstall called another home's link "a folder named like one but not a link"** (same row, 02 §2). The dry run's `links` step now counts the two kinds apart: links not proven to be this home's, and folders that are not links. `TestUninstallLinksLeftAloneByKind`; f99611b4; RC c6.
- **The window kept the old list after an outside `plan use`** (row "Window follows an outside list switch" (a), 16 G8, 07 §1.3; round 1 found it on Can it run). On focus the window now draws the visible page again when the open list changed (not on the guide). `testdata/outsidechange.mjs`; da530ebc; RC c7: Can it run's pill followed `archo plan use`.
- **A source check's background task was named "RimArcho"** (row "Updates page", 16 §2.9). A Workshop, SteamCMD, Git or page check now names its source. `TestSourceCheckTaskNamesItsSource`; 3f139925; RC c8.
