## Harness notes

`vm.ps1 exec` of a script ending in a pipeline with `Select-Object -First` stops the child's output pipe early: a `pack build` piped like that was cut off mid-copy (the next build said "a build of this pack is running" until the process ended). `archo` commands (even read-only ones such as `looks`, `library`) answer "another launch or credit replacement is running" while `test run` holds the launch lock, so the CLI is unusable for the whole 17 minutes of a hung 1.7 run. No harness script failed otherwise.
