## Bugs (open)

1. **"When saved" still checks after the first edit** (row "Quieter automatic checks", 16 §8.9, `internal/surface/gui/needscache.go` `autoAnalyzeLocked`). Severity: medium. With Settings › game log › check files automatically = when saved, an edit in the list editor started `analyze --background` 2.6 s later. Repro: set "when saved"; open Launch or Can it run (or let Can it run refresh after a check ends); go to the editor and enable one Mod: a check starts after the 2 s settle. A second and third edit 15 s apart start none. Cause: `needsAsked` is set whenever Launch or Can it run reads findings and is only cleared when a check starts, so any earlier visit lets the next settled edit check. Seen three times (14:45:58, 14:48:05, 14:51:37). "Off" works: no check after edits, Save, or opening Can it run.
2. **After deleting an oversized Player.log, Launch's last-game row goes blank and Game log shows RimWorld 1.7's log** (row "Oversized game logs", 06 §4, 16 §2.3). Severity: medium-low. Repro: 1.6 Game Config with the shared default folder, `Player-prev.log` present, a stale `…\Logs\Player.log` from a 1.7 run in the same folder (the snapshot has one from 2026-11-21); delete Player.log from the size badge. Launch's "上次游戏" line stays an empty, `aria-hidden` placeholder across navigation; Game log opens `Logs\Player.log` (1.7.5014, 11-21 09:00, "按 1.7 解读") with "把它的错误列入能不能跑"; `archo log` reads the same file and `archo status` calls it a stale 1.7 log. Expected: the 1.6 `Player-prev.log` (as the round 2 fix 4dfcc662 does when only it is left), or "the last run's log was not found". The fallback to `Logs\Player.log` probably predates 1.1.4; the new delete action makes it one click away.
3. **"Add note" on a copy glues the note to RimArcho's automatic text** (row "Mod aliases and notes", 16 §4.1, `detail.js` `noteEl`). Severity: low. Mod library, a Workshop copy whose note box shows "工坊订阅，11 月 21 日首次发现 / 由 RimArcho 生成"; row menu › 添加备注…, type "菜单备注 R114 note", Enter: the saved copy note is "工坊订阅，11 月 21 日首次发现菜单备注 R114 note". The editor opens with the automatic text (`start = i.note || i.auto`) and the caret at its end, so typed text runs on without a break. Either start empty for "add note" or select the automatic text.
4. **A background check almost stops while pages are switched non-stop** (row "Can it run during a check", 16 §8.9). Severity: low. While 150 page switches ran over 45 s, the automatic check used about 0.01 core for 35 s and finished about 75 s after it started; the same check with the window idle took 8 s. Can it run itself stayed prompt (below), so this only delays fresh findings while someone keeps clicking.

## Nits

1. Released 1.1.3 meeting a 1.1.4 home says only `store: unsupported schema version 45 (want 44)`; a player who rolls back gets no hint to update RimArcho.
2. The launch size badge reads "138.0 MB" for 72 MiB + 66 MiB (binary megabytes labelled MB).
3. "archo save" with an unchanged list adds an identical version every time (v296, v297 …). This is as 09 §2 says (only launches skip one), but a script that saves in a loop made 290 versions.
4. After the round, Updates lists Archo Monitor "代码 −2" (the round driver's DLL added and removed by `round.ps1`), a test-tool artefact.
5. Changing `ui.lang` from the CLI needs a window restart; `ui.theme` applies on reload.
