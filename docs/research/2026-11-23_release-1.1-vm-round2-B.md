## Open: decisions for the player

- **Archo's animation costs 4–7 % of a core in the VM** (rows "Archo stays alive", "Archo on five pages"; 16 §10). 12 RimArcho/WebView2 processes over 30 s on Can it run: Archo animated 4.2–6.7 % of one core, still 1.0 %, off 0.8 %. The target is ≤ 2 %. The VM renders in software, so a real GPU will be lower; worth one measurement on real hardware before deciding.
- **V8 size bars: one huge Mod makes every other bar 1 %.** In this library Progression: Soundtrack (4.6 GB) is 100 % and almost every other Mod reads 1 %. A log or rank scale would show differences; a linear scale is what the spec says.
- **The game log's "the log text" section stays English in zh/ja** ("first at", "message", "nearby": the text `archo log` prints). Everything else on the zh/ja pages is translated except game data and Mod descriptions.
- **Can it run does not refresh by itself while it stays in front** with nothing clicked: an outside list switch shows on focus or navigation (fixed above), not on its own. Good enough unless an agent switches lists while the player watches the page.
