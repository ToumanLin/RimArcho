Archo Monitor 是 RimArcho 启动器的游戏内辅助 Mod. 它记录游戏的实时报错和加载阶段, 把每条报错指向可能的问题 Mod.
[list]
[*]不改变任何游戏内容.
[*]随时加入, 随时移除.
[*]几乎没有性能影响.
[/list]
要看到分析结果, 请下载 RimArcho (免费, MIT 开源). 上次 RimArcho 发布在工坊被社区管理员下架了, 所以这里只提供下载链接 (见下).

[img]https://raw.githubusercontent.com/ToumanLin/RimArcho/master/docs/assets/workshop-monitor/zh/header-02-rimarcho.gif[/img]
简洁高效且占用小的 RimWorld 启动器和 Mod 管理器: 少纠结 Mod, 少查报错, 多玩游戏. [strike]RimArcho 有最可爱的 Archo 酱[/strike]
[list]
[*][b]多版本多语言:[/b] 目前支持Windows(稳定)和Linux(测试), 支持英语, 中文, 日语.
[*][b]轻量:[/b] 业务部分 47MB 内存, 峰值 <250MB, GUI 日常 ~100MB (RimSort, RimCrow 普遍 500+MB, 以我的450Mods列表测试).
[*][b]迁移:[/b] 目前支持迁移 RimSort/RimCrow/RimPy, 可导入 Mod 列表, 别名, 备注, 标签, 颜色标记, 忽略的警告, 排序规则; 已有的不重复导入.
[*][b]排序算法:[/b] 基于 40,326 条玩家报错日志 (26GB, 且每周更新) 和 5,143 个 Mod 分析而来, 我认为RimArcho的排序算法是目前全社区最好的.
[*][b]报错和冲突:[/b] 基于 40,326 条报错日志, 我统计了报错模式并标注严重程度 (并发现大部分红字不用太关心); 同时发现了一些高频率冲突的 Mod, 如果你一起启用了, RimArcho中会提示.
[*][b]Archo Monitor:[/b] 拿到游戏外看不到的游戏内动态信息, 更方便定位报错和 debug.
[*][b]存档分析:[/b] 存档需要哪些 Mod; 去除或加入 Mod 会损坏/丢失内容/无伤大雅.
[*][b]Mod 副本:[/b] 一键创建并替换; 副本不随 Steam 自动更新, 不怕更新带来新报错.
[*][b]多游戏版本:[/b] 管理多个游戏版本和配置 (是的, 可以同时玩 1.6 和 1.7), 通过 SteamCMD 下载其它版本, 一键备份当前游戏版本 (泰南耀斑防护, 笑).
[*][b]订阅:[/b] 支持 GitHub 和 LoversLab, 自动检查更新.
[/list]

RimArcho同时提供了Archo MCP和 RimWorld Probe SKILL:
[list]
[*][b]Archo MCP:[/b] RimArcho提供了47个MCP工具: 从提供正确的 Mod 目录, 到返回精准的报错日志, 再到启动游戏自己测试, Archo MCP提供了RimWorld debug的全套工具.
[*][b]RimWorld Probe SKILL:[/b] RimArcho一并提供了Mod探针骨架, 允许你的AI Agent自己搭建控制游戏的探针Mod, 因此你的Agent可以自己测试游戏. 举例子来说, 你再也不用琢磨如何用语言向你的Agent描述囚犯在何时何处何地无法寻路了.
[/list]
Archo MCP的开发目标是: 玩家只需说一句"有问题", Agent 就自己看问题, 修复, 启动游戏验证, 然后告诉你.
我用真实玩家报错日志和真实 Mod 做了测试情景, 在虚拟机中测试. 接入 Archo MCP 的 Pi Agent (DeepSeek 4.1 Flash) 对比不接入: 正确率 67% → 100%, token 最多省 50%.
