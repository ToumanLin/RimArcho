RimArcho 启动器的游戏内辅助 Mod. 记录游戏的实时报错和加载阶段, 把每条报错指向可能的问题 Mod.
[list]
[*]不改变任何游戏内容.
[*]随时加入, 随时移除.
[*]几乎没有性能影响.
[/list]
要看到分析结果, 请下载 RimArcho (免费, MIT 开源). 上次在创意工坊分发 RimArcho 被社区管理员下架了, 所以这里只提供下载链接 (见"下载").

[img]https://raw.githubusercontent.com/ToumanLin/RimArcho/master/docs/assets/workshop-monitor/zh/header-02-rimarcho.png[/img]
简洁高效且占用小的 RimWorld 启动器和 Mod 管理器: 少纠结 Mod, 少查报错, 多玩游戏. [strike]RimArcho 有最可爱的 Archo 酱[/strike]
[list]
[*][b]占用小:[/b] 业务部分 47MB 内存, 峰值 <250MB, GUI 日常 ~100MB (RimSort, RimCrow 普遍 500+MB).
[*][b]排序:[/b] 基于 40,326 条玩家报错日志 (26GB) 和 5,143 个 Mod 分析而来, 我认为是目前全社区最好的.
[*][b]报错和冲突:[/b] 从这些日志统计报错模式并标注严重程度 (大部分红字不用太关心); 日志里时常冲突的 Mod 会提醒.
[*][b]配合 Archo Monitor:[/b] 拿到游戏外看不到的游戏内动态信息, 更方便定位报错和 debug.
[*][b]存档分析:[/b] 存档需要哪些 Mod; 去除或加入 Mod 会损坏/丢失内容/无伤大雅.
[*][b]Mod 副本:[/b] 一键创建并替换; 副本不随 Steam 自动更新, 不怕更新带来新报错.
[*][b]多游戏版本:[/b] 管理多个版本和配置 (是的, 可以同时玩 1.6 和 1.7), 通过 SteamCMD 下载其它版本, 备份当前版本 (泰南耀斑防护, 笑).
[*][b]订阅:[/b] 支持 GitHub 和 LoversLab, 自动检查更新.
[*][b]迁移:[/b] 从 RimSort, RimCrow, RimPy 导入 Mod 列表, 别名, 备注, 标签, 颜色标记, 忽略的警告, 排序规则; 已有的不重复导入.
[*][b]Archo MCP:[/b] 47 个工具: 找得到正确的 Mod 目录, 看得准清洗过的报错日志, 摸得到 (Agent 启动游戏自己测试).
[*][b]RimWorld Probe SKILL:[/b] Agent 能启动游戏, 载入存档, 实际操作和截图. 囚犯无法寻路? 不用你描述, 它自己看.
[/list]

[img]https://raw.githubusercontent.com/ToumanLin/RimArcho/master/docs/assets/workshop-monitor/zh/header-03-ai.png[/img]
你只需说一句"有问题", Agent 就自己看问题, 修复, 启动游戏验证, 然后告诉你.
我用真实玩家报错日志和真实 Mod 做了测试情景, 在虚拟机中测试. 接入 Archo MCP 的 Pi Agent (DeepSeek 4.1 Flash) 对比不接入: 正确率 67% → 100%, token 最多省 50%.
