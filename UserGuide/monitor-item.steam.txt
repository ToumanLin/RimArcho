Archo Monitor is RimArcho's in-game companion Mod. It records what Player.log cannot say in ArchoMonitor.log in the save data folder: the XML file and Def being loaded when an error happens, which Mods own the code and Harmony patches on the stack, and how many errors came after the game stopped logging. RimArcho reads it to show the evidence for each problem in Can it run.

Load it right after Harmony and before Core so it sees every Mod load. It is cheap by design: a repeated message costs one hash lookup; writes are buffered and errors reach the disk at once.

RimArcho ships Archo Monitor and installs it itself, so you don't need to subscribe; subscribing lets Steam keep it up to date.

Download archo-<version>-windows-amd64.zip, unzip it into any folder and double-click RimArcho.exe. From then on RimArcho checks for and installs its own updates.
The executables are not code-signed, so the first time you run one Windows may say "Windows protected your PC": choose More info, then Run anyway.
